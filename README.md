# 🧠 AI Prompt Organizer

A simple yet expandable web app for saving, organizing, and reordering your best AI prompts. Built with vanilla HTML, CSS, and JavaScript, it’s ideal for students, developers, creators, and anyone who frequently works with AI tools like ChatGPT, Claude, or Midjourney.

## 🚀 Features

- Save, edit, and delete prompts
- Filter prompts by category (Essay, Coding, Image Gen, Other)
- Drag-and-drop prompt reordering
- Light/Dark mode toggle
- Export all prompts to `.txt`
- Built-in prompt templates on first launch

## 🌱 Future Plans

In future versions, the app will:
- Use AI to improve and refine user prompts automatically
- Offer auto-tagging and prompt clustering
- Support sync with cloud (Firebase/Supabase)
- Markdown export and Notion integration

# 🧠 AI Prompt Organizer

A simple yet powerful web app for saving, organizing, and managing your best AI prompts. Built with vanilla HTML, CSS, and JavaScript, it's perfect for students, developers, creators, and anyone who frequently works with AI tools like ChatGPT, Claude, or Midjourney.

## 🚀 Features

### 📝 Prompt Management
- Save, edit, and archive prompts
- Auto-save drafts (never lose your work)
- Drag-and-drop prompt reordering
- Export all prompts to `.txt`

### 🔍 Organization
- Filter prompts by category
- Create custom categories
- Live search through titles and content
- Archive instead of delete (keep your history)
- View archived prompts separately

### ⭐ Favorites & Dates
- Mark prompts as favorites
- Filter to show only favorites
- See creation date for each prompt
- Sort and organize by date

### 🎨 UI/UX
- Light/Dark mode toggle
- Clean, modern interface
- Responsive design
- Built-in prompt templates on first launch

## 🌱 Future Plans

In future versions, the app will:
- Use AI to improve and refine user prompts automatically
- Offer auto-tagging and prompt clustering
- Support sync with cloud (Firebase/Supabase)
- Markdown export and Notion integration
- Prompt version history
- Prompt sharing and collaboration

## 📦 Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/tairqaldy/ai-prompt-organizer.git
   cd ai-prompt-organizer
   ```

2. Open `index.html` in any modern browser.

✅ No build tools or dependencies required.

## 🛠 Tech Stack

- HTML5
- CSS3 (with variables for themes)
- JavaScript (ES6+)
- SortableJS for drag-and-drop
- LocalStorage for data persistence

# 🛣️ AI Prompt Organizer — Development Roadmap

This file tracks the current features, planned improvements, and long-term goals for the AI Prompt Organizer project.

---

## ✅ Completed Features

- Save, edit, delete AI prompts
- Filter prompts by category
- Drag-and-drop prompt reordering (Sortable.js)
- Light/Dark mode toggle
- Export prompts to `.txt` file
- Initial useful prompt templates
- Red delete button on hover

---

## 🧠 Short-Term Plans
